# 🌿 Cultiva

O **Cultiva** é um ecossistema focado em transformar qualquer pessoa em um "dedo verde". A plataforma centraliza o e-commerce de kits de jardinagem com o aprendizado contínuo, garantindo a sobrevivência das plantas através de guias interativos e alertas de manutenção.

## 🚀 O Problema
A alta mortalidade de plantas domésticas nas mãos de iniciantes devido à falta de instrução e insumos corretos.
